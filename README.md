
# Superstore Sales Analysis Dashboard

## 📊 Project Overview

This project analyzes the Sample Superstore dataset using SQL Server and Power BI to understand sales, profit, orders, and business performance.

## 🛠️ Tools & Technologies

- SQL Server / SSMS
- Power BI
- SQL
- Data Visualization
- Dashboard Development

## 📌 Key Analysis

- Total Sales, Profit, Orders & Quantity
- Sales by Category and Sub-Category
- Profit by Category and Sub-Category
- Sales by Region and State
- Sales by Segment and Ship Mode
- Yearly and Monthly Sales Trends
- Top Performing and Loss-Making Products
- Customer-wise Sales and Profit Analysis

## 📈 Dashboard

![Superstore Sales Analysis Dashboard](Superstore_Dashboard.png)

## 🔍 Key Insights

- Technology generated the highest category sales and profit.
- West region had the strongest sales performance.
- Phones was one of the strongest sub-categories.
- Some high-sales products and customers generated negative profit.
- The dashboard provides interactive filtering using Region, Category, Segment and Ship Mode slicers.

## 🎯 Project Objective

The objective of this project was to strengthen practical skills in SQL-based data analysis and interactive Power BI dashboard development.
